# Gold Tools Buff

Crafted golden swords, pickaxes, axes, shovels, and hoes have 300 durability. This applies when crafting in either the crafting table or the player inventory.

## Build

Run `gradlew.bat build` on Windows. The built mod JAR will be in `build/libs`.

Requires Java 25, as configured by the 26.3 Fabric template.
